🧠 Gerador de Prompts — Estruturas C.O.R.P.O & P.R.O.M.P.T

Um gerador de prompts baseado nas estruturas de Engenharia de Prompt ensinadas no DevClub pelo professor Rodolfo Mori, permitindo criar prompts profissionais para desenvolvimento de sites, aplicativos, automações e projetos diversos.

📦 Como Usar

Baixe ou clone o repositório:

git clone https://github.com/seu-usuario/seu-repositorio.git


Abra o arquivo index.html em qualquer navegador.

Preencha os campos das estruturas.

Clique em Gerar Prompt.

Copie e use seu prompt em qualquer IA.
